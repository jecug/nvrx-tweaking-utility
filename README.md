# Nvrx PC Tweaking Utility

**A Windows performance utility that debloats Windows, hardens privacy, tunes GPU and BIOS settings and runs 52 isolated tweak scripts - built in C++ with a custom ImGui interface.**

A Windows 11 PC tweaking utility built in **C++ / ImGui (MSVC)**. Fifty-two isolated tweak scripts across seven categories, a one-click Recommended flow, an honest BIOS Tweaker and a per-Game optimizer, all from one binary.

> **Note:** This repository is **source-available only**. You may read and learn from the code, but copying, modifying, redistributing, or using it in your own projects is prohibited. See [LICENSE](/jecug/nvrx-tweaking-utility/blob/main/LICENSE).

## Features

| Section | What it does |
| --- | --- |
| **Tweaks (7 categories)** | 52 isolated scripts: Win32Priority, MMCSS, FTH, HAGS, FSE, GameMode, GPU optimization for NVIDIA and AMD, NTFS and power plan tuning, network stack tuning, seven privacy shields, debloat (OneDrive, Outlook, Windows AI, 60+ services), app debloats (Chrome, Brave, Edge, Firefox, Discord, TikTok LIVE Studio), security hardening and cosmetic customization. |
| **Recommended** | One-click batch of 42 curated tweaks. Interactive tools (Geek Uninstaller, Autoruns) run last so the silent batch never stalls. Destructive rows stay manual by design. |
| **BIOS Tweaker** | Editable checklist built live from a SCEWIN (AMI) dump: 81 documented rules with honest "On Board / Not On Board / Set In BIOS" states. Entries the dump cannot prove never get hidden or fabricated, and "typed" values are shown, never auto-written. Applied through a SCEWIN-64 import with an automatic pristine backup. |
| **Game Tweaker** | Per-game config optimizer. Close the game before applying. |
| **Overview** | System status, one-click actions, restore point and a manual reboot button. |

Every tweak runs in its own isolated script. `Nvrx.bat`, the tweak source, is normalized by `util/gen_scripts.py` into the embedded `main/scripts.cpp` at build-prep time.

## Distribution (ZIP)

This source is distributed as a ZIP archive. The archive contains only the source code - **no `bin` build outputs** are included. To use it:

1. Extract the ZIP (e.g. `Source Code.zip`).

2. Open `NvrxTweaks.sln` in Visual Studio 2022.

3. Build the **Release | x64** configuration.

4. Run the built `.exe` **as Administrator**.

## Recommended safety steps

Before applying tweaks:

1. **Create System Restore Point** - the button is right on the Actions panel.

2. **BIOS flow** - the pre-edit dump is kept automatically at `C:\Nvrx\BIOS\nvram.txt.bak` the moment you send an import. To roll the BIOS back, copy that file over `bios_import.txt` and run `SCEWIN_64.exe /I /S bios_import.txt` directly (not through the app, which regenerates the plan from your picks).

3. **BIOS Tweaker scope** - Intel CPUs and desktop boards with the AMI/SCEWIN dump format only. On other boards rows honestly degrade to advice, they never hide or invent entries.
